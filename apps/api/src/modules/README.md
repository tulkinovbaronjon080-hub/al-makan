# Module scaffold

Empty folders, one per module from the brief (§32), so each phase has a fixed place to land without restructuring the tree. None are wired into `AppModule` until their phase starts.

| Module | Lands in |
|---|---|
| auth, users, businesses | Phase 1 (done) |
| customers, orders | Phase 2 |
| products, catalog | Phase 3 |
| calculator | Phase 4–5 |
| production | Phase 6 |
| inventory, locations | Phase 7 |
| store, pos | Phase 8 |
| transfers | Phase 9 |
| suppliers, purchases, payments, finance | Phase 10 |
| reports | Phase 11 |
| notifications | as needed alongside the module that triggers them |
